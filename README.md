# Sandbox1

AI駆動開発の練習用です

## TODO アプリ

依存ライブラリなしの静的Webアプリです。ブラウザの localStorage にデータを保存します。

### 使い方

`index.html` をブラウザで開くだけで動きます。

```sh
# 例: ローカルサーバーで開く場合
python3 -m http.server
# → http://localhost:8000 にアクセス
```

### 機能

- タスクの追加（入力して Enter または「追加」ボタン）
- 完了 / 未完了の切り替え（チェックボックス）
- タスクの編集（テキストをダブルクリック）
- タスクの削除（× ボタン）
- フィルター表示（すべて / 未完了 / 完了）
- 完了済みタスクの一括削除
- localStorage による自動保存（リロードしても保持）

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | スタイル |
| `app.js` | ロジック（状態管理・描画・保存） |
